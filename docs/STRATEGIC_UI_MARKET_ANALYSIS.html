① UI 专家核心判词：视觉过载与信任破口

品牌“贴纸波普”基因极佳，但 60+ 同屏粗黑框 削弱层级，字体未加载、薄荷绿低对比度、“7种 vs 12种 / 4K vs 2K”矛盾 与 15MB 首页裸图 是国际化上线前的头号阻断项。

② 市场专家核心判词：避开泛工具陷阱

纯靠 $4.99 一次性静态贴纸极易陷入“做一套就流失”的 CAC 倒挂陷阱。应以 “毛孩子/萌娃数字分身 + POD 实体周边” 为尖刀，叠加 LINE/微信/Twitch 创作者订阅工厂 撑起高 LTV。

UI-01 · 文案数据失实：“7 种 vs 12 种”及“4K vs 2048px”

P0 阻断级
messages/zh.json:24 · styles.ts:13 · PackExporter.tsx:291

首页文案写“7 种精选锁定画风”，下方实际渲染 12 种；全站反复承诺“4K 1:1”，但线上实际输出 2048×2048（2K），且导出页直接向用户暴露了真实像素。海外市场存在极高 Stripe 争议与差评风险。

国际级改造：动态读取 STYLE_PRESETS.length；统一将“4K”更正为“超清 HD / 2K 宫格（单张最高 683px）”，或为 Pro 用户提供真正的 4096px 超分选项。

UI-02 · 首页 14.98 MB 裸图性能炸弹

P0 阻断级
public/styles/*.png (12 files) · [locale]/page.tsx:97

12 张画风预览图均为 0.88–1.59MB 的未压缩 PNG，合计 14.98MB，首页和 Studio 均用原生 <img> 裸拉，在移动 4G 与海外跨区网络下 LCP 灾难性恶化。

国际级改造：全部转换为 480×480 WebP/AVIF（体积压缩至 <400KB，提速 37×），加入骨架占位与显式尺寸防布局抖动（CLS）。

UI-03 · Hero 首屏零视觉锚点，无法 3 秒看懂核心价值

P0 阻断级
src/app/[locale]/page.tsx:18-51

视觉类 AI 产品的首屏居然全是纯文字，无任何“真实宠物/自拍照 → 一整套 9 宫格贴纸 → 聊天实景气泡”的视觉证明。下方画风卡也只是单只橘猫头像，看不出“整套表情包”的震撼感。

国际级改造：升级为 Split Hero（左文案 + 右动态 3 态对比卡片）：直观展示真实原图一键裂变为 3×3 完整表情并弹出至仿微信/iMessage 聊天气泡。

UI-04 · 全站缺失 Footer 与人脸照片隐私信任背书

P0 阻断级
src/app/[locale]/layout.tsx:52-60

用户需要上传自己、伴侣、宝宝和宠物照片，但全站无 Footer、无隐私政策、无商业授权说明与“照片绝不用于模型训练 / 定期自动销毁”承诺，海外 GDPR/Stripe 审核与用户心理安全感均严重不足。

国际级改造：增补国际化 Footer（Privacy / Terms / Commercial License / FAQ / Contact），在上传框底部置入微型加密隐私承诺徽章。

UI-05 · 中文创作页满屏露出英文 Pose 动作提示

P0 阻断级
src/config/themes.ts · StudioWorkspace.tsx:794 · api/packs/route.ts:122

Step 4 在中文语言下直接渲染英文 slot.pose（如 "cheerfully waving hello"），且后端硬编码覆盖了用户的 pose 定制，普通中文用户根本无法理解或微调每一格的动作设计。

国际级改造：为 themes.ts 全面补齐地道的 poseZh 中文动作标签，并允许用户点击单格微调表情/动作关键词。

UI-06 · 核心卖点（透明贴纸与白边）被折叠隐藏

P0 阻断级
src/components/exporter/PackExporter.tsx:63, 356-404

默认导出带纯白底板的方形图，把透明抠图与贴纸白边藏在不起眼的 <details> 折叠框里。白底方块发到深色聊天或微信中显得极不专业，掩盖了团队已写好的优秀 EDF 白边算法。

国际级改造：引入 AI 语义分割精抠（WebGPU RMBG / BiRefNet），将“干净透明贴纸”设为默认推荐输出，并以仿真实聊天对话气泡替代冰冷棋盘格作为主预览场景。

UI-07 · Studio 927 行单体长表单（~4500px）与游客上传拦截

P1 体验摩擦
src/components/studio/StudioWorkspace.tsx:256, 400-926

4 个巨型垂直区块堆叠（含 12 张大画风图 + 16 格输入框），移动端需滚动 10+ 屏；未登录用户拖入照片直接被 401 报错清空，首屏转化断崖流失。

国际级改造：桌面端改为“左配置 + 右实时贴纸蓝图预览”分栏工作台；支持游客免登录先完整配好并本地暂存草稿，提供“试一试示例猫猫”一键体验按钮。

UI-08 · 切换宫格或主题时静默清空所有自定义文案

P1 体验摩擦
src/components/studio/StudioWorkspace.tsx:195-208

用户精心修改完 9 个格子的梗图文案后，若切换 3×3 ↔ 4×4 或配文语言，buildDefaultSlots 会直接覆写全部编辑记录且无任何提醒或撤销。

国际级改造：追踪已编辑格子 dirty 标记：切换宫格尺寸保留前 9 格文案；切换主题前触发轻量确认或提供“撤销覆写”Toast。

UI-09 · 声明字体未加载 + WCAG 色彩对比度违规

P1 体验摩擦
src/app/globals.css:21 · page.tsx:48 · PricingClient.tsx:237

globals.css 声明了 "Nunito" 却从未通过 next/font 加载；奶油底上的薄荷绿文字 #2EC4B6 对比度仅 2.3:1（WCAG AA 要求 ≥ 4.5:1），亮珊瑚按钮白字仅 2.85:1。

国际级改造：接入 Fredoka + Plus Jakarta Sans + Noto Sans SC；文本绿加深至 #0F766E（5.4:1），主按钮珊瑚红精调至 #E04848 或深墨底配高对比白字。

UI-10 · 全屏 60+ 粗黑描边造成“新拟态视觉疲劳”

P1 体验摩擦
src/app/globals.css:26-60 · StudioWorkspace.tsx

几乎每个卡片、输入框、胶囊、画风卡和 16 个文案格均套用 border-2 border-[#1E1B2E] 硬黑框，视觉权重高度均等，用户无法在 0.5 秒内捕捉主操作焦点。

国际级改造：实施 三层视觉梯度（Progressive Pop）：仅主卡片与主 CTA 保留 2px 墨色硬描边，次级容器退为 1.5px 柔和边框，仅在选中态亮起硬阴影。

UI-11 · 导航栏金币不显示余额 + 切换语言暴力整页刷新

P1 体验摩擦
src/components/Navbar.tsx:74-81 · LocaleSwitchLink.tsx:16

右上角金币图标旁边显示用户名而非积分余额（移动端只剩孤零零一个图标）；切换中英文调用 window.location.reload() 直接清零正在填写的表单。

国际级改造：顶部直接呈现 🪙 20 积分 实时余额胶囊与用户下拉菜单；改用 next-intl 客户端路由切换并持久化草稿状态。

UI-12 · 导出规格与移动端“最后一公里”严重断层

P1 体验摩擦
src/components/exporter/PackExporter.tsx:435-546

缺少 WhatsApp WebP（512px <100KB）、LINE（370×320+Cover/Tab）、Discord/Slack 规格；手机端下载 .zip 几乎无法导入微信或 WhatsApp，且无法重绘单张画崩的贴纸。

国际级改造：补齐全球主流 IM 渠道规格与 Telegram Bot 一键直装；手机端提供“长按存图 / 复制透明图 / 系统分享”；加入单格 2 积分精准重绘。

UI-13 · 20–60 秒同步等待期焦虑与页面保活脆弱性

P2 质感精修
StudioWorkspace.tsx:820-847 · api/packs/route.ts:179

受 Workers 30s waitUntil 限制，只能挂起 5 分钟 HTTP 长连接并警告“请勿关闭页面”，手机切微信即断连失败，且等待期只有单调秒表。

国际级改造：切换异步任务队列 + 站内通知，允许随时离开；等待期展示“逐格涂鸦拟态骨架动效”缓解体感时长。

UI-14 · 作品库缺少“同角色再创一套”与分享裂变入口

P2 质感精修
src/components/packs/PacksGallery.tsx · CLOUDFLARE_DEPLOYMENT.md:110

作品库仅有查看和删除，无搜索、无角色归档、无复购按钮；且列表直接返回 2K 原图 URL 曾触发 Workers Free 2018ms CPU 超限崩溃。

国际级改造：生成 R2 WebP 缩略图供列表加载；卡片增加「用同角色再画一套（Remix）」与「生成分享海报/链接」裂变按钮。

UI-15 · 定价页缺乏价值锚点、商业授权说明与本土支付

src/components/pricing/PricingClient.tsx · config/pricing.ts

国际级改造：补齐单套均价标签、权益对比表、商用授权保障及 FAQ；落地 schema.ts 已预留的微信支付/支付宝及人民币阶梯价。

PART 03 · DEFENSIBLE MOAT ARCHITECTURE

护城河深度剖析：摒弃“伪壁垒”，构建五大复利护城河

在基础大模型能力全面平权的 2026 年，任何单点 Prompt 或浅层套壳都会在两周内被竞品抄平。真正的护城河必须建立在用户资产切换成本、垂直工作流深度、文化社区网络效应与数据/成本飞轮之上。

✕ 清醒剥离：三大“伪护城河”

1. 12 套预设画风与 Prompt 模板

高质量视觉提示词极易被逆向复刻，竞品 1–2 周即可追平，只能作为冷启动亮点而非长期壁垒。

2. 调用的底层生图大模型 API

OpenAI / Gemini 中转对全行业开放，属于通用水电煤，不构成任何排他性竞争优势。

3. 基础 3×3 切图与 Flood-Fill 抠图

常规前端 Canvas 切格与颜色容差抠图开源随处可见，且对浅色毛发/白色衣物容错率低。

✓ 重兵构筑：五大复利“真护城河”

① Character DNA 角色基因库（高切换成本壁垒）

把“一次性 Pack”升维为长期数字资产 Character。沉淀宠物/人像的标准参考锚点与高分样本，老用户每逢节日或新梗 30 秒一键续画第 2~10 套，资产越厚越不愿离开。

② 端到端垂直工作流深度（巨头懒得做、小厂做不全）

打通「多图生图 → 单格局部重绘 → 零错字前端矢量艺术字层 → AI 端侧精抠 & 自研 Felzenszwalb EDF 丝滑白边/刀版线 → Telegram/WA/LINE/微信一键直达 & POD 印制」全链条。

③ 文化热梗模板生态 +「一键拍同款（Remix）」网络飞轮

每周上新中/英/日/韩流行热梗、节日与职场包，每张在聊天中传播的表情都是活广告，点击落地页 10 秒“用我家宠物拍同款”，将 CAC 压低至行业均值 1/3。

④ 专有偏好与质检数据飞轮（一次可用率 > 92%）

收集用户单格重绘、文案修改与下载偏好数据，持续优化防越界/防畸变自动质检与专属画风 LoRA，碾压行业 55%–65% 的平均成品率。

⑤ 客户端算力卸载 + 边缘 R2 结构性毛利护城河

延续并放大当前“浏览器端切图/描边/WebGPU 抠图/动效合成 + Cloudflare R2 零出站流量费 + 智能分级模型路由”架构，同等定价下比纯服务端 GPU 竞品高出 20%+ 毛利安全垫。
